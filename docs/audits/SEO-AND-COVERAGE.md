# SEO audit and test-coverage gaps (Phase 9, batch 1)

**Date:** 2026-11-14 · **Agent:** 5 · **Scope:** (A) a crawl-based SEO audit of the storefront in both locales; (B) untested domain logic and error paths in the API.

Severity: **high** means a sitewide or money-visible defect. **Medium** means a defect that loses indexing, rich results or crawl budget on part of the site. **Low** means hygiene, or content the owner supplies. A finding is closed only when it is fixed with a test, or when it is escalated.

## How this was verified

- **Real API, not the mock.** A private Laravel server ran on `:8345`. It used its own SQLite file, seeded with `migrate --seed` and `DemoDataSeeder`, and a storefront token from `toymart:storefront-token`. Sitemaps were generated from the same data. The Next.js storefront ran `next dev` on `:3845` against that server.
- **The crawl.** A crawler-UA crawl (`bingbot`, which gets blocking metadata) started from `/`, `/bn` and every sitemap URL. It followed every internal link, with up to three query variants per path. It covered **500 URLs** across both locales and every template: home, listings with facets, sorts and cursors, products, brands, categories, blog posts, guides, blog archives, CMS pages, cart, search, track, delivery charge and flash sale.
- **What was checked on each page:** status code; exactly one canonical (absolute, in the page's locale, no stray parameters); hreflang `en`/`bn`/`x-default`, reciprocal; title and description (present, unique, length); OG and Twitter tags; one `<h1>`; `<html lang>`; robots meta; and JSON-LD. The JSON-LD was validated with the storefront's own `lib/seo/validate.ts` against Google's required properties.
- **Sitemap checks.** Every sitemap URL was re-fetched and had to be 200, indexable and self-canonical. Every indexable, self-canonical page had to be in the sitemap.
- **Afterwards:** a re-check of each fix against the live servers, plus the new gate `e2e/seo-crawl.spec.ts`, which runs the same checks against the mock API in CI.

## Findings: test coverage (Task B)

**Coverage numbers: not measured.** Neither pcov nor xdebug is installed. PHPUnit 12 no longer supports phpdbg (it printed "No code coverage driver available"). Installing an extension would change the machine's global PHP, so it was not done. A structured review was used instead. To get numbers, `pecl install pcov` and add a CI coverage job. That is an owner or lead decision.

**Method:**
- Probe tests swept every `api/v1` route for the RFC 9457 contract.
- Each queued job was mapped to its `failed()`, `release()` and backoff branches, and every job class was grepped for in `tests/`.
- Each driver's error branches were read against its tests.
